# Axiom.Mesh.Testing

An in-memory [Axiom.Mesh](https://github.com/DeadMoon0/Axiom.Mesh) of any number of nodes for tests: one fake clock per mesh, fake discovery with partitions, in-memory stores and pipes, scripted peers that speak raw AMP/1, and waits backed by subscriptions, never by sleeps.

## Status

Phase 1a, in progress: a skeleton; the harness follows with the transport milestone.

Namespace: `Axiom.Mesh.Testing`. Depends on `Axiom.Mesh.Host`.
