# Axiom.Mesh.Cli

`axiom-mesh`, the command line of [Axiom.Mesh](https://github.com/DeadMoon0/Axiom.Mesh): a user client of the local protocol, installed as a .NET tool, that explains every failure in one line and never prints a stack trace for a known fault.

## Status

Phase 1a, in progress: `axiom-mesh --version` prints the tool's version; the commands follow.

Namespace: `Axiom.Mesh.Cli`. Depends on `Axiom.Mesh.Local` only, never on the Host or its engine.
