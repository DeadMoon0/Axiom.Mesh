<architecture>
    A user client of Axiom.Mesh.Local only (no System.CommandLine, plan decision D9). Program is the only shell (console, environment, disk, Ctrl-C); everything else is a function of CliEnvironment. Most commands connect as the user; write and package publish connect as the external service cli (decision D4) with AXIOM_MESH_SERVICE_TOKEN or services.cli.token from config.json, register their kind, and write: a Message via WriteEntry.Of(package, MessagePayload.ToBody()) (Axiom.Mesh.Payloads; the Host parses no payload, the envelope's references and redacts come from ToBody); a folder via Trees.PublishDirectoryAsync (Local helpers: Chunks, ChunkLists and Trees put with PutObject), WriteEntry a Version whose references name the root Tree, then Unpin of every object put (LOCAL-SPEC 9.5). package materialise reads the newest Version with ListHistory (reverse, kind Version, limit 1), runs Fetch (recursive) on its Tree so what is missing comes from the peers, then StoreFiles.MaterialiseAsync with Existing fail|replace|merge on this side of the pipe (Materialise and PutFile left the Host in LOCAL-SPEC draft 4). Pair commands subscribe to topic pairing before they act and wait for the state they need: pair show and pair join until the SAS shows, pair confirm until the pairing ended. watch subscribes to entries from HelloAck.storeSeq + 1 and resubscribes after a lapse. Packed as the .NET tool axiom-mesh; published as Native AOT (the command line with the ILCompiler argument --noscan, STRUCTURAL-DEBT 47) by Scripts/package.ps1|.sh, which run the smoke and zip axiom-meshd + axiom-mesh per RID for the GitHub Release; install.ps1|.sh call axiom-mesh host install, so the scripts and the command share one registration. The Windows task ends conhost, not the daemon: the plan stops the daemon by its path (StopStep).
</architecture>

<best_practices>
    Add a command as a row of CommandSpecs.All and a record in Commands/; keep parsing and output pure and test them in Cli.Tests/Rules; every known failure leaves as CliFailure (one line, one exit code); ids accept full hex or an unambiguous prefix (IdMatch), Packages and users also their exact name; --json on every list via Utf8JsonWriter (no reflection). Test end to end with TestNode.CliAsync against a TestMesh whose Local options configure the cli service.
</best_practices>

<pitfalls>
    Never reference Core or Host (ServiceOrAppConventionTests); CliPaths must stay equal to the Host's HostPaths (Host.Tests: CliHomeRegressionTests). Never print a stack trace for a known fault. Plan Windows paths with the backslash and Linux paths with the slash whatever OS plans them (tests run both plans on both runners); never call Path.GetFullPath on a path of the other platform. FollowPackage needs the Package listed first (connect and settle before following in tests). The token is read per run; a Host that never started has written none. In PowerShell scripts do not name a function Cli (an alias of Clear-Item).
</pitfalls>
