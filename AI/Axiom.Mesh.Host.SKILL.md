<architecture>
    The only place time, sockets, disk and the pipe enter. HostProgram is a function of its inputs; Program reads arguments, the environment and Ctrl-C/SIGTERM and passes a stop token. Start order: config.json (defaults written on first start, a cli token generated with IEntropy), the key directory (refused when wider than the owner on Linux), the pipe (the single-instance guard: a taken pipe stops the start before the store is touched), the database, then the node. The pipe listeners are the only platform code: Windows creates every instance with CreateNamedPipe (FILE_FLAG_FIRST_PIPE_INSTANCE on the first, PIPE_REJECT_REMOTE_CLIENTS on all, an owner-only DACL plus a system service's allow list) because NamedPipeServerStream does not set reject-remote; it reads a client's first bytes (impersonation needs them; 10 s, 16 at once), then pid (GetNamedPipeClientProcessId), executable (QueryFullProcessImageName) and the DOMAIN\name of the impersonation token, and replays the bytes through PrefixedStream. Linux binds a 0600 socket after a refused-connection probe of a stale file and reads SO_PEERCRED and /proc/pid/exe; the user is the uid. PipeHost decides each connection with PipeAdmission and hands admitted ones to node.Local.AdoptAsync. mDNS and broadcast start once node.WhenIdentityAsync completes.
</architecture>

<best_practices>
    Refuse a wrong configuration at start with recovery steps (MeshConfigurationException, naming the key). Every key has a default; keep README's table, HostRegressionTests' default snapshot and the sections in step. Print and log home, pipe and mesh endpoint at start. Keep identity reading in the listeners and the decision in PipeAdmission (pure). Tests run the daemon in process with a temp home (TempHome), AXIOM_MESH_PIPE unique, mesh.port 0 and mdns/broadcast false.
</best_practices>

<pitfalls>
    The assembly is Axiom.Mesh.Host; a Native AOT publish names the binary axiom-meshd (TargetName). The daemon is never a NuGet package (IsPackable false); it ships in the release zips with axiom-mesh. PipeOptions.CurrentUserOnly cannot be combined with a PipeSecurity, and NamedPipeServerStream never sets PIPE_REJECT_REMOTE_CLIENTS: create pipes with CreateNamedPipe. GetImpersonationUserName and RunAsClient fail until data was read from the pipe. GetImpersonationUserName returns the bare name; the listener uses the impersonation token's DOMAIN\name. System.Text.Json's source generator sets init-only properties a file leaves out to null: the config sections use set. A console process that ignores Ctrl-C passes that to its children.
</pitfalls>
