# Axiom.Mesh.Protocol

AMP/1, the mesh wire protocol of [Axiom.Mesh](https://github.com/DeadMoon0/Axiom.Mesh) (SPEC.md), described with ProtoStream: the messages, the session states, the limits, the pure rules a session checks (`Hello`, listings, wants) and the pairing protocol `axiom-mesh-pair/1`.

## Status

Phase 1a, in progress: a skeleton holding the ALPN name; the definition follows.

Namespace: `Axiom.Mesh.Protocol`. Depends on `Axiom.Mesh.Model` and `Axiom.ProtoStream`.
